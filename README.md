# 🛡️ Cyber Sentinels — Academy of Cyber Defense

> Think like a defender. Beat the hackers.

**Cyber Sentinels** is an interactive, browser-based cybersecurity training game designed to teach students real-world threat defense through active simulation rather than passive reading.

## 🚀 Missions

1. **🎣 Phish Hunt:** Navigate a chaotic inbox of 10 real-world email and SMS scenarios to separate legitimate communications from look-alike traps.
2. **🔐 Password Forge:** Test your credentials against a live cracking simulator with real-time entropy calculation and crack-time metrics.
3. **⚡ Rapid Fire:** Fast-paced speed quiz covering core defense concepts, encryption, 2FA, and safe browsing habits.
4. **🎭 Mind Games:** Handle interactive chat-based social engineering scenarios where attackers leverage urgency and trust.
5. **👾 NULLBYTE (Boss Fight):** A high-stakes, clock-driven finale combining everything you've learned to take down a rogue network AI.

---

## ✨ Features

* **Zero Build Steps:** Built with vanilla JavaScript modules (`ESM`), modern CSS variables, and HTML5. No heavy frameworks or npm build pipelines required.
* **Procedural Audio Engine:** Custom sound effects synthesized entirely in-browser using the **Web Audio API** (no external audio assets needed).
* **Dynamic Content Bank:** Randomized challenge queues ensure high replayability.
* **Local Persistence:** Tracks user progression, XP ranks, and collectible badges securely via `localStorage`.
* **Accessible & Responsive:** Fully responsive layout optimized for desktop and mobile, complete with keyboard shortcuts (`1`–`4`, `Enter`).

## 🛠️ Local Development

Clone the repository and run it locally with any static file server:

```bash

git clone [https://github.com/your-username/cyber-sentinels.git](https://github.com/your-username/cyber-sentinels.git)

# Navigate into directory
cd cyber-sentinels

# Run with a local server (e.g., Python or Node)
npx serve

python3 -m http.server 8000
